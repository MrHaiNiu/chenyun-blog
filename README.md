# chenyun-blog

A personal blog built with Vue 3, Vite, and TailwindCSS.

## Tech Stack

- **Framework:** Vue 3 + TypeScript
- **Build Tool:** Vite
- **Styling:** TailwindCSS
- **Content:** Markdown-based posts
- **Features:** Hue theme customization, music player, search, timeline, project showcase, friend links

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
