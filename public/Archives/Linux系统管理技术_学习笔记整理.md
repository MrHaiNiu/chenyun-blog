### 1.1 Linux 系统简介

- **Linux 创始人**：Linus（林纳斯·托瓦兹）

## 模块二 · Shell 命令基础

### 2.1 学习方法与命令使用约定

> 🎯 **本阶段学习方法和要求**：牢牢记住并练熟常用 Shell 命令，按命令功能分类学习记忆。

**命令使用约定**：

- 在终端中输入一条命令，然后回车键执行它。如果命令执行失败或发生异常，肯定会有报错信息，我们通过分析报错信息去解决问题。**如果某条命令执行后没有任何反馈信息，证明它执行成功了（没有消息就是最好的消息）**。
- 几乎所有命令都支持参数，命令名和参数之间以及不同参数之间要用空格（可以多个）分隔。如果某个参数内容中含有空格，那必须用单引号或双引号将该参数括起来。
- 命令的参数支持短风格和长风格形式，功能是一样的，可以根据自己喜好选择使用。

### 2.2 帮助手册 man

- `man`：manual，帮助手册，通过该命令可以查看命令或函数的使用方法。戏称：**在 Linux 系统有问题找"男人"**。
- 有中括号 `[ ]`，表示参数可有可无；中括号 `[ ]` 内参数带有 `...`，表示参数有多个。

> 💡 **小贴士**：手册不是教程，不需要全部看完和看懂，也不需要精读细读，要带着目标一目十行跳着看，快速找到我们需要的内容然后结束。

| `poweroff` | 关机 |
| `shutdown` | 关机或重启，`-r` 参数表示重启，`-h` 参数表示关机 |

### 2.4 网络配置命令

### 2.5 软件包管理

#### 2.5.1 软件包安装方式

Linux 系统中安装软件包的常用方式：

- 使用软件包管理器从资源服务器下载软件包然后安装
- 手动下载软件包到本地进行安装
- 可执行文件（绿色软件，解压之后运行就行）
- 源码包（自己下载软件的源码，然后解压编译安装，比较繁琐，需要自己安装编译环境构建环境）

|-----------|-------------|-----------|

>
> 为了提升下载软件包的速度，建议进行**换源操作**，将默认软件源服务器地址更改为国内镜像服务器地址。

#### 2.5.3 Ubuntu 系统上软件包管理常用命令

| 命令 | 作用 |
|------|------|

#### 2.5.4 实操：换源、更新系统、安装常用软件

```shell
sudo apt update
sudo apt upgrade -y

```

> 💡 **小贴士**：在 Linux 系统中有些命令普通用户没有执行权限，只有 root 用户才能执行，此时可以在该条命令的最左边加上 `sudo` 前缀，表示以 root 用户执行该条命令。
>
> **root 用户**是 Linux 系统内置的超级管理员。

#### 2.5.5 实操：安装 QQ

## 模块三 · 用户和组群管理

### 3.1 用户与组群概念

现代操作系统（Linux、Windows、MAC 等）都是支持多用户的。

| 概念 | 说明 |
|------|------|
| **用户（User）** | 使用系统的一个身份表示 |
| **组群（Group）** | 方便批量管理用户和用户之间的通信 |

- **root 用户**是 Linux 系统内置的用户，它是系统管理员用户，具有最高权限。除了 root 用户之外，我们可以自己创建用户。每个用户都有自己独立的配置和工作环境，互不影响。
- 在 Linux 系统中，每个用户必须有且只有一个**主组群**（也称初始组群），可以加入任意个其他组群。

> 💡 **小贴士**：
> - 用户：user
> - 组群：group
> - **管理就是四个字：增删改查（CRUD，Create - Retrieve - Update - Delete）**
> - 属性信息也称为字段

### 3.2 组群管理命令

| 命令 | 作用 |
|------|------|
| `groupadd` | 创建一个新组群 |
| `groupdel` | 删除一个已存在的组群 |
| `groupmod` | 修改（modify）一个已存在组群的属性信息（比如 GID、组群名字等） |
| `cat /etc/group` | 查看系统中所有组群的信息，组群信息放在 `/etc/group` 文件中 |

### 3.3 用户管理命令

| 命令 | 作用 |
|------|------|
| `useradd` | 创建一个新用户 |
| `userdel` | 删除一个已存在用户 |
| `usermod` | 修改一个已存在用户 |
| `cat /etc/passwd` | 查看系统中所有用户信息，用户信息存放在 `/etc/passwd` 文件中 |
| `passwd` | 给用户设置密码。Linux 系统不允许空密码用户登录系统，用户密码加密后存放在 `/etc/shadow` 文件（影子文件），该文件默认只有 root 用户可读 |
| `su` | 切换当前用户，select user。如果不指定目标用户，则切换到 root 用户。常用参数：带上 `-` 表示同时切换当前文件夹为目标用户的主文件夹，并且用目标用户的环境变量 |
| `exit` | 注销当前用户 |
| `id` | 查看用户的 UID、主组群、附加组群信息 |

> 💡 **小贴士**：
> - 在创建新用户时，如果不指定其主组群，Linux 系统会自动创建一个与用户名同名的组群作为该用户的主组群。
> - 每个用户通常都有一个自己的主文件夹（或称主目录），用户的主文件夹的名字通常和用户名相同，**普通用户的主文件夹通常在 `/home` 下，root 用户的主文件夹是 `/root`**。
> - **Linux 终端为了安全（防止旁边的人偷窥密码），输入密码时没有回显（Echo）效果**。

## 模块四 · 文件系统管理

### 4.1 文件系统概念

- **文件系统（File System）**：管理磁盘上的文件数据的程序。
- **Linux 设计哲学**：一切皆文件。
- 注意：文件夹是文件的一种。
- `/etc` 放配置文件。

> 💡 **小贴士**：文件夹也称目录。

### 4.2 Linux 系统中的文件类型（7 种）

| 类型 | 说明 |
|------|------|
| 普通文件 | |
| 文件夹 | |
| 软连接 | |
| 管道文件 | |
| 套接字文件 | |
| 字符设备文件 | |
| 块设备文件 | |

### 4.3 文件路径

**根文件夹（Root Directory）**：也称为根目录，Linux 系统最顶层的那个文件夹，用 `/` 表示。

**文件路径（File Path）**：描述一个文件在磁盘上的存储位置。只要知道一个文件的路径，就能找到它和操作它。

文件路径有两种表示方式：

| 路径类型 | 说明 | 示例 |
|---------|------|------|
| **绝对路径** | 基于根文件夹定位 | `/home/cy`、`/bin/bash`、`/root/music/a.mp3` |
| **相对路径** | 基于当前文件夹定位，用 `.` 表示当前文件夹，用 `..` 表示当前文件夹的上一层文件夹 | `./a.out`、`./junge/code/hello.c`、`../music/a.mp3`、`../../../cy` |

> 💡 **小贴士**：
> - `/` 称为斜杠，`\` 称为反斜杠。
> - 在 Linux 系统中根文件夹以及路径分隔符都用斜杠（`/`）表示，而 Windows 系统中的路径分隔符采用反斜杠（`\`）表示。

### 4.4 Linux 系统根目录下的文件夹意义

| 目录 | 含义 |
|------|------|
| `/etc` | 存放各种配置文件 |
| `/home` | 家目录，存放普通用户的主要目录 |
| `/root` | root 用户的主目录 |
| `/bin` | binary，存放所有用户能执行的命令（程序） |
| `/sbin` | super binary，存放系统管理员能执行的命令（程序） |
| `/boot` | 存放 Linux 系统启动所需要的重要文件 |
| `/dev` | device，存放各种设备文件 |

### 4.5 文件夹操作命令

| 命令 | 作用 |
|------|------|
| `pwd` | print working directory，打印当前（工作）目录 |
| `cd` | change directory，改变当前文件夹 |
| `mkdir` | make directory，创建文件夹，`-p` 表示创建多级目录，例如：`mkdir -p /a/b/c/d` 可以创建多级文件夹 |
| `rmdir` | remove directory，删除空文件夹，用的很少，更多使用 `rm -rf` 命令 |

> 💡 **小贴士**：
> - `sudo su` 切换到 root 用户。
> - **解读终端（/bin/bash）提示符的意义**：`当前用户名@主机名:当前文件夹路径 $/#`，`$` 表示为普通用户，`#` 表示为系统管理员。
> - 在 Linux 系统中，文件名首字符是 `.` 的文件就是**隐藏文件**。
> - 每个文件夹下面都有两个特殊的隐藏文件夹，名字是 `.` 和 `..`，前者是当前文件夹，后者就是当前文件夹的上一级文件夹。

### 4.6 文件查看与编辑命令

#### 4.6.1 文件夹和普通文件通用命令（创建与查看）

| 命令 | 作用 |

#### 4.6.2 vim 编辑器

软件的用户界面（UI，User Interface）分为两种：

| 类型 | 全称 | 说明 |
|------|------|------|
| **GUI** | Graphical User Interface | 图像化用户界面 |
| **CUI** | Character User Interface | 字符化用户界面 |

**vim 是 vi 的增强版**，功能和用户体验比 vi 更强，现在基本使用 vim。

| 模式 | 用途 |

**模式切换**：

### 4.7 文件属性与权限管理

#### 4.7.1 ls 命令详解

| 命令 | 作用 |
|------|------|
| `ls` | list，查看某个文件夹下的文件信息，或者查看某个普通文件的属性 |
| `ls -l` | 显示文件的详细属性信息 |
| `ls -a` | 显示所有（all）文件，包括隐藏文件 |
| `ls -d` | 查看文件夹自己的属性 |
| `rm` | remove，用于删除文件夹时通常使用 `-rf` 参数 |
| `chmod` | change mod，修改文件模式属性（即文件的操作权限信息） |
| `chown` | change ownership，修改文件所有者和所属组群 |

**chmod 的两种用法形式**：

1. 使用 3 个八进制数字表示三组权限：`r` 用 4 表示，`w` 用 2 表示，`x` 用 1 表示，有某个权限就加上对应的数字。
2. 使用 `u`、`g`、`o`、`a`、`r`、`w`、`x`、`+`、`-`、`=` 表示三组权限。

#### 4.7.2 ls -l 命令执行结果详解

详解 `ls -l` 命令的执行结果（文件的详细属性信息）：

| 列号 | 含义 |
|------|------|
| 第 1 个字符 | 文件类型，有 7 种情况：`-` 表示普通文件，`d` 表示文件夹，`l` 表示软连接 |
| 第 1 列后面的 9 个字符 | 文件的操作权限，3 个字符为一组，共表示 3 组权限。第 1 组表示文件所有者的操作权限，第 2 组表示同组人的操作权限，第 3 组表示其他人的操作权限。每一组权限依次为 `r`、`w`、`x`。`r` 表示可读（read），`w` 表示可写（write），`x` 表示可执行（execute），如果没有对应的权限，其对应位置用 `-` 表示 |
| 第 2 列 | 硬链接数，同一个文件有多个文件名 |
| 第 3 列 | 文件的所有者（即所属用户），默认为创建该文件的用户 |
| 第 4 列 | 文件的所属组群，默认为所有者的主组群 |
| 第 5 列 | 文件大小，默认以字节为单位，带上 `-h` 参数可以以更可读的形式显示文件大小 |
| 第 6 列 | 文件的最近修改时间 |
| 最后一列 | 文件名 |

#### 4.7.3 文件权限的意义

在 Linux 系统中，每个文件都有一个所属用户（即主人）和所属组群。

**对于普通文件**：

| 权限 | 含义 |
|------|------|
| `r` | 可读取其数据，比如 `cat`、`more`、`less` 等命令 |
| `w` | 可以修改其数据内容，比如 `vim`、`nano` |
| `x` | 可执行该文件，如果该文件不是可执行文件，即使具有 `x` 权限也没有实际意义 |

**对于文件夹**：

| 权限 | 含义 |
|------|------|
| `r` | 可以读取它内部的文件信息，比如 `ls` 等命令 |
| `w` | 可以在它内部创建或删除文件，比如 `touch`、`rm` 等命令 |
| `x` | 可以打开进入该文件夹，比如 `cd` 命令 |

> 💡 **小贴士**：
> - 当前文件的删除取决于它所在的文件夹是否有 `w` 写权限。
> - **`x` 权限是 `w` 和 `r` 权限的基础**。

### 4.8 链接文件（Link File）

链接文件分为两种：

| 类型 | 说明 | 创建命令 |
|------|------|---------|
| **软连接（Symbolic Link）** | 也称为符号链接，其数据内容就是另一个文件的路径，我们称它指向另一个文件，用 `l` 表示其类型，和 Windows 平台上的快捷方式文件是一样的。**建议使用绝对路径**。 | `ln -s` |
| **硬链接（Hard Link）** | 硬链接就是一个文件名，使用 `ln` 命令创建。**注意：不能给文件夹创建硬链接！** | `ln` |

> 💡 **小贴士**：文件就是存放在磁盘上的一份数据，文件名就是这份数据的一个标签，用于表示这份数据，方便访问。一个文件是可以有多个文件名的。这些文件名都称为该文件的硬链接。

### 4.9 文件拷贝与移动命令

| 命令 | 作用 |
|------|------|
| `cp` | copy，拷贝文件，拷贝文件夹时必须带上参数 `-r` |
| `mv` | move，移动文件，通常用该命令实现文件重命名操作（在同一个文件夹下移动可以实现重命名） |
| `wget` | 从网络上下载文件。常用参数：`-O` 指定下载后的文件名 |

### 4.10 文件打包和压缩

#### 4.10.1 打包与压缩的概念

| 概念 | 说明 |
|------|------|
| **文件打包** | 为了方便管理和传输，将多个文件整合在一起构成一个文件，这个文件就是包文件，后缀名通常为 `.tar` |
| **文件压缩** | 使用某个数据压缩算法将一个文件变小，好处是可以减少存储空间占用，提升网络传输效率。压缩文件不能直接使用，需要进行解压缩操作得到原始文件才能使用 |
| **压缩包** | 将多个文件打包一起得到一个包文件，然后对包文件进行压缩处理后得到最终的压缩包文件 |

#### 4.10.2 常用数据压缩算法

- zip
- gzip
- bzip
- xzip
- rar（闭源，商业化）

#### 4.10.3 文件打包命令

```shell
# 打包
tar -cvf junge.tar hello.c test.c asdf

# 查包
tar -tvf junge.tar

# 解包
tar -xvf junge.tar  # 默认解压到当前文件夹下，可以通过 -C 解压到指定目录下
```

#### 4.10.4 文件压缩常用命令

```shell
# gzip 压缩和解压
gzip junge.jpg        # 得到压缩后的文件 junge.jpg.gz
gunzip junge.jpg.gz   # 得到原始文件 junge.jpg

# bzip2 压缩和解压
bzip2 junge.jpg       # 得到压缩后的文件 junge.jpg.bz2
bunzip2 junge.jpg     # 得到原始文件 junge.jpg

# xz 压缩和解压
xz junge.jpg          # 得到压缩后的文件 junge.jpg.xz
xunz junge.jpg        # 得到原始文件 junge.jpg
```

#### 4.10.5 常见压缩包格式及操作命令

```shell
# .tar.gz 格式
tar -zcvf junge.tar.gz hello.c mage.jpg longge.mp3    # 打包并压缩
tar -tvf junge.tar.gz                                 # 查看压缩包
tar -xvf junge.tar.gz                                 # 解压缩，默认解压到当前文件夹下，可以通过 -C 指定解压路径

# .tar.bz2 格式
tar -jcvf junge.tar.bz2 hello.c mage.jpg longge.mp3   # 打包并压缩
tar -tvf junge.tar.bz2                                # 查看压缩包
tar -xvf junge.tar.bz2                                # 解压缩，默认解压到当前文件夹下，可以通过 -C 指定解压路径

# .tar.xz 格式
tar -Jcvf junge.tar.xz hello.c mage.jpg longge.mp3    # 打包并压缩
tar -tvf junge.tar.xz                                 # 查看压缩包
tar -xvf junge.tar.xz                                 # 解压缩，默认解压到当前文件夹下，可以通过 -C 指定解压路径

# .zip 格式
zip -r junge.zip hello.c mage.jpg longge.mp3          # 打包并压缩
unzip -l junge.zip                                    # 查看压缩包
unzip junge.zip                                       # 解压缩，默认解压到当前文件夹下，可以通过 -d 指定解压路径
```

### 4.11 文件名通配符

文件系统管理命令都支持文件名通配符，从而可以轻松实现对文件批量操作：

| 通配符 | 含义 |
|--------|------|
| `*` | 表示若干个任意字符（可以为 0 个） |
| `?` | 表示任意一个字符 |

### 4.12 重定向符

**重定向符（`>` 和 `>>`）**：将其左边命令的执行结果写入到文件中，而不是在终端窗口显示。

| 符号 | 行为 |
|------|------|
| `>` | 如果目标文件不存在就会自动创建一个新文件；如果目标文件已存在，会**清空**文件中的原有数据再写入新数据（覆盖效果） |
| `>>` | 如果目标文件不存在就会自动创建一个新文件；如果目标文件已存在，会**保留**文件中的原有数据并在末尾写入新数据（追加效果） |

## 模块五 · 任务（进程）管理

### 5.1 进程概念

现代操作系统（比如 Linux、Windows、HarmonyOS）都是多任务系统的操作系统。

| 概念 | 说明 |
|------|------|
| **任务** | 一个任务通常就是一个进程（Process） |
| **进程（Process）** | 正在运行的程序（Program） |
| **程序（Program）** | 可执行文件 |
| **PID** | Process Identification，操作系统给每个进程分配的唯一整数编号，用于标识不同的进程 |

> 💡 **小贴士**：
> - **软件（Software）** = 程序 + 文档
> - **硬件（Hardware）** = PCB、芯片、元器件等
> - 命令就是程序，通常存放在 `/bin` 或 `/sbin` 下，通过 `which` 命令可以查看命令的路径。

### 5.2 进程管理常用命令

| 命令 | 作用 |
|------|------|
| `ps` | process snapshot，进程快照，查看系统中当前时刻所有进程的信息。不带任何参数查看的是在当前终端中运行进程信息，如果带上 `-e` 或 `-aux` 参数可以查看系统中所有进程的信息 |
| `top` | 实时刷新显示系统中所有进程信息 |
| `kill` | 通过 PID 结束某个进程。常用参数：`-9`（抽象：9 号刀很锋利） |
| `killall` | 通过程序名批量结束进程 |
| `fg` | foreground，将当前正在后台执行的进程调度到前台执行 |
| `bg` | background，将当前在后台暂停的进程执行起来 |

### 5.3 前后台进程控制

| 快捷键 / 符号 | 作用 |
|--------------|------|
| `CTRL + C` | 结束当前终端中在前台运行的进程 |
| `CTRL + Z` | 将当前正在前台执行的进程调度到后台并暂停它 |
| `&` | 在命令的末尾加上该符号，可以让这条命令在后台执行 |

## 模块八 · Shell 命令进阶技巧

### 8.1 管道符 `|`

**管道符 `|`**：左边命令执行结果传输给右边命令处理（作为文件处理）。

- `wc`：字符统计。
- 例如：`ps -e | grep firefox`

### 8.2 逻辑与 `&&`

**`&&`**：先执行左边命令，如果左边命令执行成功就接着执行右边的命令，否则不执行右边命令。

- 例如：`mkdir junge && cd junge`，`gcc hello.c && ./a.out` 等

### 8.3 分号 `;`

**`;`**：先执行左边命令，无论是否执行成功都会接着执行右边命令。

- 例如：`ip a ; ls -l` 等

## 模块九 · Shell 脚本

### 9.1 Shell 脚本概念

**Shell 脚本**：将需要执行的若干条命令写入一个文件保存，后面只需要执行一次该文件就将自动将它里面的所有命令从上往下自动执行一次，这个文件就是 Shell 脚本程序。后缀名通常为 `.sh`。

Shell 脚本中可以直接使用 Shell 命令作为语句，支持变量、常量、流程控制结构、函数等功能，所以它也是一门编程语言。**非常适合实现各种系统管理任务**。

### 9.2 编程语言主要分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **解释型** | 也称为脚本语言，源代码直接可以运行，不需要编译，需要解释器，在运行时边翻译边执行，所以效率较低 | Shell、Python |
| **编译型** | 源代码不能直接运行，必须通过编译器编译处理转换为二进制可执行文件才能执行，所以效率较高 | C、C++、Java、C# 等 |

### 9.3 Shell 脚本示例

#### 9.3.1 最简单的 Shell 脚本（hello.sh）

```shell
#!/bin/bash
echo hello,world
```

> 💡 **小贴士**：在 Shell 脚本中，`#` 表示注释内容，**第一行注释通常用于指定解释器程序**。

#### 9.3.2 批量创建文件夹的脚本示例

```shell
#!/bin/bash

echo "任务开始执行..."

mkdir /junge

for i in {1..1000}; do
        mkdir /junge/${USER}$i
        echo "junge yyds!" > /junge/${USER}$i/data
done

echo "任务执行完毕！"
```
