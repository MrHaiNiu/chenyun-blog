[3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

 

**示例 1:**

```
输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
```

**示例 2:**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3:**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

 

**提示：**

- `0 <= s.length <= 105`
- `s` 由英文字母、数字、符号和空格组成



```cpp
#include <iostream>
using namespace std;

/*
	O(n^2)
	i循环，每遍历一个字符，初始化 ACII数组，从当前字符开始记录最长长度，遇到重复则 break j for
	j循环，遍历每一个字符最长非重复长度，即二重循环记录查询当前遍历字符出现次数是否 >1
	chCnt[ASCII 码]>1，说明 s[i] 到 s[j] 重复，更新 maxLen，结束 j 循环
*/
int lengthOfLongestSubstring1(string s) {

    int len = 0;
    int maxLen = 0;

    for(int i=0;i<s.size();i++){
    	int chCnt[256] = {0};
        len = 0;

		if(maxLen >= s.size()-i+1){  // 最长长度 >= 剩余字符串长度，可以提前返回，但提升不大
        	return maxLen;
        }

        for(int j=i;j<s.size();j++){
            chCnt[s[j]]++;
            if(chCnt[s[j]]>1){
                break;
            }else len++;
            maxLen=max(maxLen,len);
        }
    }

    return maxLen;
}  
// 通过 运行时间 150ms


/*
	维护一个队列，l到r，这个区间内无重复
	如果和 r 重复了，弹出左侧的字符，即 l++
	i 循环不断入队，r 不断往右移，此时判断 l 是否和 r 重复
	s[r] 入队，cnt[对应的ASCII]++
	以右侧为标准，只有右侧的 cnt[ASCII] <= 1 时，左侧才弹出 s[r] 这个字符
	例如：b c d a a 这个字符串-> r在d时候，队列：{b c d a} -> r 移动到第二个a 时，队列：{b c d a a} 
	此时 cnt['a'] = 2，l不断右移(l++)，直到队列：{ a }
	在这个过程中不断 maxLen=max(maxLen,r-l+1)
*/
int lengthOfLongestSubstring2(string s) {
    queue<char> myQue;
    int l=0,r=0;
    int cntNum[256]={0};
    int maxLen = 0;
    for(int i=0;i<s.size();i++){
        r = i;
        cntNum[s[i]]++;
        while(cntNum[s[r]]>1){
            cntNum[s[l]]--;
            l++;
        }
        maxLen = max(maxLen,r-l+1);
    }
    return maxLen;
}
```
