[4. 寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/)



给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。

 

**示例 1：**

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2
```

**示例 2：**

```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```

 

**提示：**

- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-106 <= nums1[i], nums2[i] <= 106`



```c

#include <iostream>
#include <vector>
using namespace std;

/*	
	个人思路：考虑归并。因为数组是有序的，否则还得采用归并排序排序
	两个有序数组归并，把较小的push进 n数组 来存储新排序好的数组
	两两比较直到其中一方全部进入 n数组
	剩下的数直接全部push进入 n数组
	期间用 i 和 j 记录两个数组的标
	偶数长度，返回( n[len/2] + n[len/2-1] )/ 2.0;
	奇数长度，返回 (double)n[len/2];
*/
double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
    vector<int> n;
    int i=0,j=0;
    double ans;
    
    while(i<nums1.size() && j<nums2.size()){ // 归并
        if(nums1[i]<nums2[j]){
            n.push_back(nums1[i]);
            i++;
        }else{
            n.push_back(nums2[j]);
            j++;
        }
    }

    while(i<nums1.size()){                   // 填充剩余元素
        n.push_back(nums1[i]);
        i++;
    }

    while(j<nums2.size()){					 // 填充剩余元素
        n.push_back(nums2[j]);
        j++;
    }

    int len = nums1.size()+nums2.size();
    // 例如 len = 4,返回下标是 1 和 2 ,即 len/2-1 和 len/2
    len % 2 == 0 ? ans = (n[len/2]+n[len/2-1])/2.0: ans = n[len/2]; 
    return ans;
}
// 通过 运行时间 0ms
int main(){
	vector<int> nums1={1,2},nums2={3,4};
	printf("ans= %lf\n",findMedianSortedArrays(nums1,nums2));


	return 0;
}
```
